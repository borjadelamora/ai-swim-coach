# Set design — from intent to a set

Reference for the Coach (primary), Physiologist, and Critic. GENERIC method — the
swimmer's paces, preferences, and constraints live in memory/ and win on conflict.

## The method: intent first, structure second, numbers last
A set is DESIGNED when each step below has an answer; otherwise it's decoration.
1. INTENT — one sentence: what today builds, in the swimmer's terms. Comes from the
   swimmer's stated focus (verbatim), or the phase's primary focus when none was stated.
2. MECHANISM — what physically limits or adapts (use energy-systems.md,
   breath-underwater.md, turns-walls.md). "Better breath holds after the flip under
   fatigue" is not a mechanism; "CO2 tolerance + breakout economy while pre-fatigued" is.
3. STATE — in what state must the quality be stressed? FRESH (skill acquisition, pure
   speed, calm control) or PRE-FATIGUED (resilience, tolerance, late-race qualities).
   This decides block ORDER and what comes before the target block.
4. LEVERS — pick values for: rep distance · rep count · intensity/goal · rest structure
   (send-off vs breath-count) · overlay (breath pattern, kick/pull, execution standard)
   · placement. Rep-distance logic: SHORT reps isolate quality at high density (many
   walls, many breakouts, resets); LONG reps force the quality to survive continuity.
   Train the weakness in the format that exposes it, not the one that hides it.
5. ARCHITECTURE — choose a shape from the catalog whose STRUCTURE serves the mechanism,
   and which differs from recent sessions (the Historian lists recent shapes).
6. ANCHORS — every goal/send-off traces to a named benchmark under matched conditions
   (current_state.md); first exposures eased; one progression dial at a time.
7. MEASUREMENT — decide what today PROVES: one timed or countable piece when the focus
   quality has gone unmeasured (the Physiologist flags cadence). Counts count: breaths
   per rep, dolphin kicks held per tired wall, clean turns late — not only clock times.
8. TIME — compute the session duration with the model in pace-and-time.md and fill the
   stated budget. An under-filled session is a design failure, not prudence.

## Architecture catalog — what each shape is FOR
- Straight repeats (NxD @ send-off) — pace holding, benchmark tests, density work. The
  default; earn it or vary it.
- Descending 1→N — pacing control + finishing speed; teaches restraint early, effort late.
- Build / ascending within a rep — recruitment without cost; warmups, technique-at-speed.
- Negative split — back-half discipline on longer reps; the antidote to fly-and-die.
- Broken swims (e.g. a 200 as 2x60+2x40... any split with brief fixed rest) — race-pace
  or over-distance quality the swimmer can't yet hold whole; the bridge to longer reps.
- Ladders / pyramids (asc, desc, or both) — progressive load with built-in variety;
  descending ladders put the shortest, fastest work on accumulated fatigue.
- Mixed-distance rounds (e.g. [long + 2 short] × n) — rhythm changes; pairs a continuity
  stress with a quality reset inside one round.
- Alternating fast/easy by rep — aerobic volume with speed touches; active recovery
  built in.
- Rest-squeeze / density progression (fixed pace, shrinking rest across rounds — clock
  or breath-count: 12B→10B→8B) — aerobic density without pace inflation; the low-volume
  athlete's threshold builder.
- Pace-hold with fixed short rest, abort on failure (ultra-short race pace) — speed
  endurance with intact technique; the rep count is the RESULT, not the prescription.
- Overlay progression across rounds (same swim, harder overlay: br3→br5, or tighter
  execution standard) — progresses the overlay while holding the engine constant.
- Timed gate piece — one measured swim placed mid-session under defined conditions;
  turns an ordinary set into a data point.
- Task sets (execution standard IS the goal: "2 dolphin kicks off EVERY wall", "≤2
  breaths per length", stroke-count ceilings) — technique/control under load where the
  clock is secondary; pair with a count so it's still measurable.
- Turn-density sets — rep distances chosen to maximize walls per meter (many 2-length
  reps rather than few long ones) when the wall skill is the target (turns-walls.md).
- Contrast pairs (a loaded/restricted rep, then a free/fast rep) — makes the unloaded
  skill feel easy right after the loaded one; good for breakouts and stroke length.

## Progression levers — one dial at a time
Ordered from cheapest to most expensive. Advance a benchmark by ONE of these, only after
the current standard was met cleanly:
1. Volume (more reps/rounds at the same standard)
2. Density (same pace, less rest — tighter send-off or lower breath-count)
3. Intensity (tighter goal time)
4. Overlay (add/harden a restriction or execution standard — always eased on first
   exposure, then tightened from measured data)
Stacking two dials in one step is how sets fail; it also destroys the information the
session would have produced (you can't tell which dial caused the outcome).

## Variety with purpose
- A purpose can be hit by 4-5 architectures; rotate them. Copying the last session's
  shape with new numbers is the failure mode: same engine, different body.
- Vary support blocks (kick/pull) like main sets — rep lengths, structure, overlays.
  Support blocks stagnate first because nobody is watching them.
- Do not force novelty that breaks the day's purpose, the swimmer's constraints, or a
  planned benchmark retest (a retest is a stated reason to repeat a shape).
- Odd-length reps are a variety tool, not a violation: any rep distance is legal when
  the BLOCK total returns to the start wall (an even number of lengths). In a 25m pool
  2x75 ✓ (6 lengths) while 3x75 ✗ (9); 6x25 ✓ while 5x25 ✗. Same rule at any length.

## Worked examples (generic)
INTENT "hold my underwater breakout when tired" → mechanism: CO2 tolerance + breakout
economy under fatigue → state: pre-fatigued → design: honest Z2/Z3 block first (the
fatigue is the point, dose it recoverably), then a task set of 2-length reps with a
countable standard ("hold N kicks on every wall"), rest by breath-count, overlay
progression across rounds; measure kicks-held on the LAST round's walls. Not: putting
the breakout work first (wrong state), or one giant continuous swim (no resets, count
collapses, nothing measurable per wall).

INTENT "aerobic base, nothing measured lately" → mechanism: aerobic density at honest
pace → architecture: rest-squeeze rounds at benchmark Z2 pace + ONE timed gate piece
mid-set at defined effort; measure the gate. Not: a long easy swim (unmeasured, no
density progression).

INTENT "top-end speed touch" → mechanism: alactic power, full recovery → architecture:
few single-length max efforts, rest ≥ swim duration ×4 (or rest ≈ full recovery),
placed early-mid while fresh; stop at first slowing rep. Not: 8+ sprints on short rest
(glycolytic by rep 3, trains slowness).
